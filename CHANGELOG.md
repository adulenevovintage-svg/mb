# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-03-21

### Added
-   **Initial Release:** Full-stack reservation system for MB Barber Shop.
-   **Real-time Bookings:** Firestore integration for live availability.
-   **Multi-Channel Notifications:** Support for Telegram, Email (Resend), and SMS (Twilio).
-   **Modern UI:** Responsive design with `motion` animations.
-   **Full Configuration:** Added Docker, ESLint, Prettier, and SEO metadata.
-   **Error Handling:** Integrated `ErrorBoundary` and custom error handling for Firestore.
-   **PWA Support:** Added `manifest.json` and favicon.

### Changed
-   **Logo Update:** Transitioned from local `logo.jpg` to a high-quality external URL.
-   **Project Structure:** Organized constants, types, and services for better maintainability.
